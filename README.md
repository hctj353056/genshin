# Deepseek V4 Pro god

## 核心理念
- 预测下一个 `(X, Y)` 二元组，替代传统token预测
- X为状态机，Y为内容
- DeepSeek API负责深度推理，壳程序负责渲染控制
- 双轨输出：颅内思考（不显示/半透明）+ 屏幕输出（可回溯修改）

## 架构
```
DeepSeek API → XY二元组 → 渲染器 → Web界面
```

## X状态定义
| 状态 | 功能 | 渲染效果 |
|------|------|----------|
| THINK | 颅内思考 | 半透明斜体，不干扰主输出 |
| OUTPUT | 输出到屏幕 | 正常显示 |
| DELETE | 删除 | 删除指定位置内容 |
| MODIFY | 修改 | 替换指定位置内容 |
| INSERT | 插入 | 在指定位置插入 |
| NEWLINE | 换行 | 换行 |
| EXEC | 执行工具 | 显示执行状态 |
| PAUSE | 暂停等待 | 闪烁等待指示器 |
| HIGHLIGHT | 高亮 | 彩色渐变/动画 |
| COPY | 复制 | 复制到剪贴板 |
| PASTE | 粘贴 | 从剪贴板粘贴 |
| ABORT | 中断 | 终止当前输出 |

## Web渲染器功能
1. **THINK区域**：侧边栏/顶部，半透明灰色背景，斜体显示
2. **OUTPUT区域**：主聊天窗口，实时输出
3. **操作历史**：底部显示所有XY操作记录
4. **回溯修改**：点击历史记录可回退到任意状态
5. **高亮动画**：HIGHLIGHT状态触发彩色渐变
6. **弹窗控制**：可拖拽、最小化、关闭
